# 阶段五决策记录

## D-1 单文件二进制选型：**Go**

| 候选 | 交叉编译 | 单文件 | 体积 | 生态复用 | 结论 |
|---|---|---|---|---|---|
| **Go** | `GOOS/GOARCH` 一行 | 静态链接，无运行时依赖 | ~10MB | 标准库 `net/http` 够用 | ✅ **选它** |
| Rust | 需 target 工具链，构建慢 | 是 | 最小 | — | 体积优势在本场景不值构建成本 |
| Node (pkg/sea) | 需分别构建 | 需打包 | 40MB+ | 复用 TS 生态 | 体积与启动速度都不划算 |

**理由**：本项目对二进制的要求只有三件事——托管静态资源、转发 `/v1/*`、FS helper。
`net/http` + `os` 标准库全覆盖，无需第三方依赖，也就没有供应链面。
交叉编译是 `GOOS=darwin GOARCH=arm64 go build` 一行，三个平台各一次即可。

⚠️ **当前状态（2026-10-23）**：Go 壳已编写并验证 —— `server/` 下 41 条 `go test` 通过，
Windows 产物 6.9 MB，darwin / linux 交叉编译通过。

**「零第三方依赖」的唯一例外（I-43）**：`golang.org/x/text/unicode/norm`（v0.16.0，Go 团队维护）。
标准库没有 Unicode 归一化，而 `fsJailVectors.json` 要求 NFD 的 `café` 与 NFC 的 `café` 视为同一路径。
仅此一处使用，不做运行时下载；若日后能删掉该向量，这个依赖也应一并删除。
